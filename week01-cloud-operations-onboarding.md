#Professional Vocabulary

Virtualization: Using virtual computer resources instead of physical hardware.
Evidence:Information that can be checked.
Finding: A result supported by evidence.
Assumption: Something believed without proof.
Escalation:Asking the correct person for help with a problem.
Sandbox: A controlled environment with limits.
Region:An AWS location where services run.
IAM: An AWS service that manages access and permissions.
Operations Playbook:A guide that records steps, evidence, and lessons.
